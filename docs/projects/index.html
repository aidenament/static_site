A collection of my work in mathematics, machine learning, and software.

Machine Learning & Software

  • Chess Eval - A set of 300 checkmate puzzles with increasingly unusual rules. Models adapted to the new rules fairly well, but struggled when the mating lines got longer.

Mathematics

  • Sum of Uniform Random Variables - How many random numbers from \([0,1]\) do you need to add before the sum exceeds 1? On average, \(e\).
  • Expected Distance to the Nearest Face of an n-Cube - A calculation of the expected distance from a random point in an \(n\)-cube to its nearest face. In two dimensions, the answer is \(1/6\).
  • Hartogs' Extension Theorem - A proof that holomorphic functions of several complex variables cannot have isolated singularities.
  • Conformal Invariance of Brownian Motion - A proof that conformal maps preserve Brownian motion up to a change of time, followed by a probabilistic proof of Liouville's theorem.
